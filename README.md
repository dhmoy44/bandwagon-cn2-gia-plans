## 三网直连到底是哪三条线路

搬瓦工三网直连 = 电信 CN2 GIA + 联通 CUP + 移动 CMIN2，分别对应中国三大运营商面向国际业务的高端通道。

- **电信 CN2 GIA**：电信等级最高的国际线路，全程走 59.43 开头的顶级节点，双向优化。它和 CN2 GT（普通 CN2）的区别在于：CN2 GT 起步虽然也走 59.43，中途却要经过 202.97 普通骨干网，白天没感觉，晚高峰容易堵。
- **联通 CUP**：联通精品网，走 AS9929 + AS10099，比普通出口的 AS4837 高一个档次。
- **移动 CMIN2**：移动的国际精品网（AS58807），可以理解为移动版的 CN2 GIA。

这三条线的共同点是绕开各自运营商拥挤的普通国际出口。同一台 VPS，线路从普通国际线换成三网直连，晚高峰的差距会比 CPU 从 2 核升到 3 核明显得多。这也是为什么选搬瓦工时，“机房和线路”比配置参数更值得花时间。

## 常见问题

**三网直连和 CN2 GIA-E 是一回事吗？**

不是。CN2 GIA-E 是套餐名，三网直连是线路组合。买 CN2 GIA-E 套餐，再把机房切到 DC6、DC9 这类标注了三网线路的机房，才是完整的“三网直连”。

**香港和日本机房算三网直连吗？**

算，但形式不同。美国的三网直连是三条不同的高端线（CN2 GIA + CUP + CMIN2），香港和日本 CN2 GIA 机房则是三家运营商都走 CN2 GIA 回程。

**KVM 套餐便宜很多，能吃到三网直连吗？**

不能。KVM 套餐不包含 CN2 GIA-E 机房，走的基本是普通国际线路，适合学 Linux、跑脚本这类对线路不敏感的用途。

**套餐内切换机房会丢数据吗？**

不会。CN2 GIA-E 在 KiwiVM 后台切换机房，数据保留，不需要重新购买。可以先试 DC6，不满意再换 DC9 或日本软银，这种灵活性在 VPS 行业里不多见。

**付款方式支持哪些？**

支持支付宝和微信支付，官网有对应的注册和付款教程，按流程下单即可。
